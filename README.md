# new-rust-project

With this VS Code extension you can create a new Rust project (Console or Library).

When creating a new project you can:
- Generate a launch.json file that uses the Visual Studio Windows debugger.
- Generate a tasks.json file that contains tasks for running Cargo build, Cargo run and Cargo check.
- Add keyboard shortcuts to keybindings.json to run above tasks (Ctrl+F5 = Run, Ctrl+Shift+B = Build, Ctrl+Shift+C = Check)
